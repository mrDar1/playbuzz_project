# CLAUDE.md

## Progress logging

Keep a running log of all work in `progress.md` at the repository root.

- After completing each task (or meaningful step), append an entry to `progress.md`. Create the file if it doesn't exist.
- Each entry should include:
  - Date (YYYY-MM-DD)
  - A short summary of what was done
  - Files created, modified, or deleted
  - Any open issues, follow-ups, or decisions made
- Append new entries at the end; never rewrite or delete earlier entries.
- Keep entries concise (a few bullet points each).

### Entry format

```markdown
## YYYY-MM-DD - <short title>
- What was done: ...
- Files: `path/one`, `path/two`
- Notes: ...
```
